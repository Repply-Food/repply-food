O painel interno da equipe Repply (Lucas Ferreira e Lucas Duarte), na mesma aplicação, em /admin. Serve para cadastrar restaurantes, ver quem parou de enviar dados, cuidar do token de envio e do acesso do cliente. É pensado para o computador, mas funciona no celular.

Regras desta tela

O que a implementação precisa respeitar. O número é a decisão registrada em docs/decisoes.md.

Quem usa e onde fica

  • Só para a equipe Repply. "Admin Repply" é um tipo de usuário da plataforma, não um cargo dentro do restaurante: para os clientes continua valendo um único login, sem cargos.D-32D-10
  • Fica no mesmo app, em /admin, num endereço que só os admins abrem.D-38
  • Pensado para o computador, mas precisa funcionar no celular.D-39

Lista de restaurantes

  • Estado do envio: em dia / atrasado / parado / fechado agora / aguardando 1º envio, com o horário do último envio.D-32D-38
  • "Atrasado" e "parado" só contam dentro do horário de funcionamento. Fora dele, "fechado agora", sem alarme.D-38
  • O e-mail de alarme sai quando um restaurante vira "parado". Vai para a equipe Repply, não para o dono.D-38D-15
  • Cadastrar restaurante.D-32
  • No celular, a lista mostra primeiro quem precisa de atenção (parado, atrasado, aguardando); o detalhe abre numa tela própria, com os mesmos blocos do computador.D-40

Restaurante selecionado

  • Nome, CNPJ, horário de funcionamento e hora em que o dia vira são editados só aqui ("Editar dados"). O dono só consulta, em Ajustes.D-35
  • Token de envio: mostrado inteiro só na hora em que é gerado; depois, só o começo ("rf_8f3k••••"). "Copiar instruções para a SCC" monta a mensagem com endereço, token e intervalo.D-38D-03
  • Troca de token: na hora de gerar o novo, o admin escolhe se o antigo para imediatamente (padrão) ou em 24h.D-38
  • Acesso do cliente: criar o login, redefinir a senha e trocar o e-mail.D-32D-38
  • Últimos envios, com os erros.D-38
  • "Ver o painel do cliente": abre o painel daquele restaurante só para leitura, para o suporte sem pedir a senha do cliente. Entra no MVP.D-38

Padrões que valem aqui

  • Botão principal ("+ Cadastrar restaurante") com fundo laranja e texto preto.contraste
  • Marca: símbolo oficial + "repply food." com ponto laranja, mais a etiqueta "admin". O tomate só aparece no símbolo, nunca depois do nome.D-42
