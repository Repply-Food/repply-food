# Etapa 5 — Tela "Hoje" · Plano de Implementação

> **Para quem executa (IA):** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar tarefa por tarefa. Os passos usam caixas (`- [ ]`).

**Objetivo:** mostrar ao dono, durante o expediente, os números do dia do restaurante quase em tempo real, fiel à tela aprovada `docs/telas/hoje.html`, com cada número vindo de uma função SQL `metrica_*`.

**Arquitetura:** funções SQL `metrica_*` (uma migration nova) calculam cada número no banco (`security invoker` — o isolamento é a RLS de `entradas`); `lib/metricas/` as consome com tipos; a página `/r/[slug]/hoje` (Server Component, atrás de `exigirCasa`) renderiza; um componente de cliente atualiza a cada ~1 min; a curva usa Recharts por um `ChartContainer` do shadcn que este plano adiciona.

**Tech Stack:** Next.js 16 (App Router, RSC), React 19, TypeScript estrito, Supabase (Postgres + RLS), Recharts 3.10, Tailwind 4, Vitest, `pg` (testes contra o banco local), decimal.js, date-fns-tz.

## Global Constraints

- **Número só por função SQL `metrica_*`** (CLAUDE.md §5, §10). A tela, o PDF (etapa 8) e o "ver painel do cliente" do admin chamam as mesmas. **Nunca recalcular métrica em TypeScript.**
- **Isolamento:** as funções `metrica_*` são `security invoker` (herdam a RLS de `entradas`: `tem_acesso(restaurante_id) or eh_admin_repply()`). Recebem `p_restaurante_id` **já verificado** pela página via `exigirCasa`. `set search_path = public`. Nascem fechadas: `grant execute ... to authenticated, service_role` na própria migration, e entram em `tests/isolamento/funcoes-fechadas.test.ts`.
- **Dinheiro:** `numeric(12,2)` no banco; as funções devolvem dinheiro como **`text`** (`::text`) para o TS receber **string**. Nunca `number` para somar centavos. Formatação só por `lib/format/dinheiro.ts` (`formatarBRL`).
- **Regras de cálculo** (metricas.md §1): só contas válidas (`removida_em is null`); paga = `pago = true`; faturamento da casa = `valor_consumido − taxa_servico` (D-14); momento da venda = `fechada_em`; dia de operação já vem gravado em `entradas.dia_operacao`; fuso do restaurante via `public.dia_operacao_de(momento, fuso, hora_virada)`; **divisão por zero → `null`** (a tela mostra "—").
- **Comparação** (metricas.md §4): média das **últimas 4 ocorrências do mesmo dia da semana com movimento (≥1 paga)**, até o **mesmo tempo decorrido**; `variacao = (hoje − média) ÷ média`; **< 2 ocorrências → não aparece** (`null`).
- **"Agora" é um parâmetro.** Toda função dependente do momento recebe `p_agora timestamptz` (a página passa `now()`; os testes passam o "agora" fixo do exemplo, `2026-10-10 02:00` no fuso da casa). Isso torna tudo determinístico e testável.
- **Migrations só se acrescentam.** Arquivo novo `supabase/migrations/20261019120000_metricas_hoje.sql`. Todas as funções são `create or replace` (idempotentes ao reaplicar no local).
- **Interface:** celular primeiro, computador sempre (D-39/D-40, breakpoints `md:` do Tailwind); claro e escuro (D-12); taxa de serviço sempre separada (D-14); contas esquecidas máx. 3 + "ver todas (N)" (D-33); cores só com significado, sempre com seta/texto (D-33); laranja só na marca e na linha de hoje.
- **Função do servidor** devolve `{ ok: true, data } | { ok: false, error }` com `error` frase do produto; falha de leitura vira tela de erro, nunca número errado nem lista vazia.
- **Verificação (CLAUDE.md §9):** `npx tsc --noEmit`, `npm run check`, `npx vitest run`, `NEXT_PUBLIC_APP_URL=http://127.0.0.1:3000 npm run build`. Testes de banco precisam do Supabase local no ar (`npm run supabase:start`).
- **Provisório** até a SCC (H5, H6, H9, B6, H7); não "consertar" regra de negócio sem conversar.

```sql
-- Etapa 5 · Funções de métrica da tela "Hoje" (docs/metricas.md).
-- security invoker: o isolamento é a RLS de entradas (tem_acesso/eh_admin_repply).
-- Dinheiro volta como text (string) para o TS não somar number.
begin;

create or replace function public.metrica_faturamento_do_dia(
  p_restaurante_id uuid, p_ate timestamptz
) returns table (
  faturamento text, taxa_servico text, contas_pagas int, pessoas_pagas int
)
language sql
stable
security invoker
set search_path = public
as $$
  with r as (select fuso, hora_virada from public.restaurantes where id = p_restaurante_id)
  select
    coalesce(sum(e.valor_consumido - e.taxa_servico)
      filter (where e.pago and e.fechada_em <= p_ate), 0)::text,
    coalesce(sum(e.taxa_servico)
      filter (where e.pago and e.fechada_em <= p_ate), 0)::text,
    count(*) filter (where e.pago and e.fechada_em <= p_ate)::int,
    coalesce(sum(e.numero_ocupantes)
      filter (where e.pago and e.fechada_em <= p_ate), 0)::int
  from public.entradas e, r
  where e.restaurante_id = p_restaurante_id
    and e.removida_em is null
    and e.dia_operacao = public.dia_operacao_de(p_ate, r.fuso, r.hora_virada);
$$;

grant execute on function public.metrica_faturamento_do_dia(uuid, timestamptz)
  to authenticated, service_role;

commit;
```

```sql
create or replace function public.metrica_comparacao_do_dia(
  p_restaurante_id uuid, p_agora timestamptz
) returns table (
  faturamento_hoje text, por_pessoa_hoje text,
  media_faturamento text, media_por_pessoa text,
  variacao_faturamento numeric, variacao_por_pessoa numeric,
  ocorrencias int
)
language plpgsql stable security invoker set search_path = public
as $$
declare
  v_fuso text; v_virada time; v_dia_hoje date; v_dow int;
  v_inicio_hoje timestamptz; v_decorrido interval;
  v_hoje_fat numeric; v_hoje_pes int;
begin
  select fuso, hora_virada into v_fuso, v_virada
    from public.restaurantes where id = p_restaurante_id;
  if v_fuso is null then return; end if;   -- sem acesso (RLS) ou inexistente
  v_dia_hoje := public.dia_operacao_de(p_agora, v_fuso, v_virada);
  v_dow := extract(dow from v_dia_hoje)::int;
  v_inicio_hoje := ((v_dia_hoje::text || ' ' || v_virada::text)::timestamp) at time zone v_fuso;
  v_decorrido := p_agora - v_inicio_hoje;

  select m.faturamento::numeric, m.pessoas_pagas
    into v_hoje_fat, v_hoje_pes
    from public.metrica_faturamento_do_dia(p_restaurante_id, p_agora) m;

  return query
  with dias as (
    select e.dia_operacao as d
    from public.entradas e
    where e.restaurante_id = p_restaurante_id and e.removida_em is null
      and e.dia_operacao < v_dia_hoje
      and extract(dow from e.dia_operacao)::int = v_dow
    group by e.dia_operacao
    having count(*) filter (where e.pago) >= 1
    order by e.dia_operacao desc
    limit 4
  ),
  pontos as (
    select m.faturamento::numeric as fat,
           case when m.pessoas_pagas > 0
                then m.faturamento::numeric / m.pessoas_pagas else null end as por_pessoa
    from dias
    cross join lateral public.metrica_faturamento_do_dia(
      p_restaurante_id,
      ((dias.d::text || ' ' || v_virada::text)::timestamp at time zone v_fuso) + v_decorrido
    ) m
  ),
  ag as (
    select count(*)::int as n, avg(fat) as media_fat, avg(por_pessoa) as media_pp
    from pontos
  )
  select
    v_hoje_fat::text,
    case when v_hoje_pes > 0 then (v_hoje_fat / v_hoje_pes)::text else null end,
    case when ag.n >= 2 then round(ag.media_fat, 2)::text else null end,
    case when ag.n >= 2 then round(ag.media_pp, 2)::text else null end,
    case when ag.n >= 2 and ag.media_fat > 0
         then round((v_hoje_fat - ag.media_fat) / ag.media_fat, 4) else null end,
    case when ag.n >= 2 and ag.media_pp > 0 and v_hoje_pes > 0
         then round(((v_hoje_fat / v_hoje_pes) - ag.media_pp) / ag.media_pp, 4) else null end,
    ag.n
  from ag;
end;
$$;

grant execute on function public.metrica_comparacao_do_dia(uuid, timestamptz)
  to authenticated, service_role;
```

```sql
create or replace function public.metrica_curva_do_dia(
  p_restaurante_id uuid, p_agora timestamptz
) returns table (minuto_do_dia int, acumulado_hoje text, acumulado_tipico text)
language plpgsql stable security invoker set search_path = public
as $$
declare
  v_fuso text; v_virada time; v_dia_hoje date; v_dow int;
  v_inicio_hoje timestamptz; v_decorrido_min int;
begin
  select fuso, hora_virada into v_fuso, v_virada
    from public.restaurantes where id = p_restaurante_id;
  if v_fuso is null then return; end if;
  v_dia_hoje := public.dia_operacao_de(p_agora, v_fuso, v_virada);
  v_dow := extract(dow from v_dia_hoje)::int;
  v_inicio_hoje := ((v_dia_hoje::text || ' ' || v_virada::text)::timestamp) at time zone v_fuso;
  v_decorrido_min := floor(extract(epoch from (p_agora - v_inicio_hoje)) / 60)::int;

  return query
  with faixas as (  -- 0, 30, 60, ... 1410 (24h em passos de 30 min)
    select generate_series(0, 1410, 30) as m
  ),
  dias as (  -- hoje (d = v_dia_hoje) + as 4 ocorrências
    select v_dia_hoje as d, true as eh_hoje
    union all
    select e.dia_operacao, false
    from public.entradas e
    where e.restaurante_id = p_restaurante_id and e.removida_em is null
      and e.dia_operacao < v_dia_hoje and extract(dow from e.dia_operacao)::int = v_dow
    group by e.dia_operacao
    having count(*) filter (where e.pago) >= 1
    order by 1 desc
    limit 5  -- hoje + 4
  ),
  base as (  -- início de cada dia de operação
    select d.d, d.eh_hoje,
           ((d.d::text || ' ' || v_virada::text)::timestamp at time zone v_fuso) as inicio
    from dias d
  ),
  acum as (  -- faturamento acumulado de cada dia até o fim de cada faixa
    select f.m, b.eh_hoje,
           coalesce(sum(e.valor_consumido - e.taxa_servico) filter (
             where e.pago and e.fechada_em <= b.inicio + make_interval(mins => f.m)
           ), 0) as acumulado
    from faixas f
    cross join base b
    left join public.entradas e
      on e.restaurante_id = p_restaurante_id and e.removida_em is null
     and e.dia_operacao = b.d
    group by f.m, b.eh_hoje, b.d
  )
  select
    f.m,
    -- hoje: só até o decorrido
    (select case when f.m <= v_decorrido_min
                 then a.acumulado::text else null end
       from acum a where a.m = f.m and a.eh_hoje limit 1),
    -- típico: média das ocorrências (quando >= 2)
    (select case when count(*) >= 2 then round(avg(a.acumulado), 2)::text else null end
       from acum a where a.m = f.m and not a.eh_hoje)
  from faixas f
  order by f.m;
end;
$$;

grant execute on function public.metrica_curva_do_dia(uuid, timestamptz)
  to authenticated, service_role;
```

(Nota ao implementador: confira a borda — a subconsulta "hoje" deve existir mesmo quando não há entrada na faixa, graças ao `left join` + `coalesce ... 0`. O `limit 5` no `dias` traz hoje + 4; se preferir precisão, separe hoje das 4 ocorrências em CTEs distintas. O teste é o juiz.)

```sql
create or replace function public.metrica_meta_do_mes(
  p_restaurante_id uuid, p_agora timestamptz
) returns table (
  faturamento_mes text, meta text, andamento numeric,
  projecao text, projecao_disponivel boolean
)
language plpgsql stable security invoker set search_path = public
as $$
declare
  v_fuso text; v_virada time; v_dia_hoje date; v_ini_mes date;
  v_fat_mes numeric; v_fat_ate_ontem numeric; v_meta numeric;
  v_dias_ate_ontem int; v_dias_no_mes int;
begin
  select fuso, hora_virada into v_fuso, v_virada
    from public.restaurantes where id = p_restaurante_id;
  if v_fuso is null then return; end if;
  v_dia_hoje := public.dia_operacao_de(p_agora, v_fuso, v_virada);
  v_ini_mes := date_trunc('month', v_dia_hoje)::date;
  v_dias_no_mes := extract(day from (v_ini_mes + interval '1 month - 1 day'))::int;

  select coalesce(sum(valor_consumido - taxa_servico) filter (where pago), 0)
    into v_fat_mes
    from public.entradas
   where restaurante_id = p_restaurante_id and removida_em is null
     and dia_operacao >= v_ini_mes and dia_operacao <= v_dia_hoje;

  -- faturamento e dias de operação com movimento ATÉ ONTEM (para a projeção)
  select coalesce(sum(valor_consumido - taxa_servico) filter (where pago), 0),
         count(distinct dia_operacao) filter (where pago)
    into v_fat_ate_ontem, v_dias_ate_ontem
    from public.entradas
   where restaurante_id = p_restaurante_id and removida_em is null
     and dia_operacao >= v_ini_mes and dia_operacao < v_dia_hoje;

  -- meta do mês, herdando a mais recente ≤ mês atual
  select valor into v_meta from public.metas
   where restaurante_id = p_restaurante_id and mes <= v_ini_mes
   order by mes desc limit 1;

  return query select
    v_fat_mes::text,
    v_meta::text,
    case when v_meta > 0 then round(v_fat_mes / v_meta, 4) else null end,
    case when v_dias_ate_ontem >= 2   -- 3º dia do mês = já houve 2 dias
         then round((v_fat_ate_ontem / v_dias_ate_ontem) * v_dias_no_mes, 2)::text
         else null end,
    (v_dias_ate_ontem >= 2);
end;
$$;

grant execute on function public.metrica_meta_do_mes(uuid, timestamptz)
  to authenticated, service_role;
```
